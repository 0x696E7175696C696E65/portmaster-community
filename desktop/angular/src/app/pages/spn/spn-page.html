Tor and WireGuard routing

Enable the Split Tunnel Module in settings, then enable Use Split Tunnel for each app you want to route.

Tor

Run a local Tor daemon and set the app's Network Interface to tor (127.0.0.1:9050), or tor://127.0.0.1:9150 for another local SOCKS port. TCP uses Tor; UDP is blocked. Keep the Tor daemon's own app routing disabled.

WireGuard

Start your own WireGuard tunnel and set Network Interface to its name or local tunnel IP. Configure the tunnel's routes and AllowedIPs with your WireGuard client. Keep that client's app routing disabled.

DNS uses Portmaster's configured resolver separately. Tor routing does not provide Tor Browser fingerprint protection or onion hostname resolution.
